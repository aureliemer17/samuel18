# Registres versionnes

Chaque registre a un format independant afin de pouvoir faire evoluer chaque
domaine sans casser les autres.

- `registre-machines.csv` : codes ouvrant une machine ou une salle.
- `registre-pages.csv` : codes saisis ou reveles par les pages d'enigme.
- `registre-indices.csv` : texte et ordre des indices par numero de carte.

Les fichiers sont separes par `;` afin de rester faciles a editer dans Numbers.
Ne modifiez pas les codes en renommant les dossiers a la main : utilisez la
commande `Gestion des archives.command`, puis l'action `Codes et enigmes`.
